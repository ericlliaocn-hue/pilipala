# pilipala 愿景

## 产品是什么

**pilipala** 是面向 **AI 短剧 / 漫剧** 的画布式创作平台：一个创作者（或小团队）在一张无限画布上，从剧本走到分镜、镜头、配音配乐和成片，模型、算力、计费都由 pilipala 托管。

它从 [infinite-canvas](https://github.com/basketikun/infinite-canvas) fork，保留画布编排体验，补上账号、预付费、任务、对象存储与受控模型网关（Anytoken 存量 + fork NewAPI 视频网关）。

仓库：[https://github.com/ericlliaocn-hue/pilipala](https://github.com/ericlliaocn-hue/pilipala)

品牌名固定为 **pilipala**（小写）。上游项目名称只出现在版权、fork 说明与工程对照里。

## 给谁用

- **短剧 / 漫剧创作者（C 端，主力）**：单人或 2–5 人小团队，做竖屏短剧、漫剧、AI MV、剧情短视频；要的是「角色稳定、镜头可控、一集能出、成本看得见」。
- **运营方**：用预付费钱包、会员和积分控制成本与收入，用任务状态机和网关看清失败与渠道成本。
- **内部实现者（人 / MiniMax）**：按 brief 交付，按 ADR 守边界。

## 竞品对照（2026-11 口径）

| --- | --- | --- | --- |
| **LibTV**（LiblibAI） | 无限画布 + 节点工作流 + Agent 入口的 AI 视频平台；文本/图片/视频/音频/脚本节点，打组重跑，画布内剪辑，宫格分镜，角色三视图，Agent Skill 一句话出短剧 | 节点体系、宫格分镜、打组重跑、托管 Agent、对外 Skill | 不拼模型首发和社区流量 |
| **AniShort** | 短剧工业化协作平台：小说拆集、角色/场景/道具清单、标准分镜脚本、3D 导演台、多人协作审片 | 剧本 → 分镜结构化、角色/场景资产库 | 不做企业级多人审片与 3D 导演台（M8 之前） |
| **TapNow** | 多模型画布 + AI 执行导演 Agent，镜头/打光/多角度控制，TapTV 社区可克隆工作流 | 「克隆同款」工作流模板、Agent 导演 | 不做电商/广告全品类，不铺 35+ 模型 |

一句话：**竞品拥有流量、模型首发或 GPU；pilipala 拥有面向短剧的画布流程、低成本高成功率的视频网关和一套干净的预付费账本。**

## 我们靠什么赢

1. **短剧流程是一等公民**：剧本、角色、分镜、镜头、配音是画布上的结构化节点，不是一堆散图。
2. **视频成本与成功率**：自有 NewAPI 视频网关做渠道 fallback、熔断、幂等，用户失败不扣费。
3. **账可审计**：冻结 → 确认 / 释放，用户和运营都看得清每一分钱。
4. **托管 Agent**：一句话或一段剧本，自动排出分镜和镜头到画布，人可以随时接手改。

## 原则

1. **账本只有一套。** 用户、额度、冻结/确认/释放只存在 pilipala 业务库。Anytoken / NewAPI 是模型网关，不是第二套用户/配额系统（[ADR 0001](./adr/0001-anytoken-not-newapi-fork.md) 经 [ADR 0008](./adr/0008-gateway-layer-video-multi-channel.md) / [ADR 0009](./adr/0009-newapi-fork-video-gateway.md) 修订）。
2. **网关只管渠道。** 渠道 Key、协议、退避、熔断、fallback 在网关；产品、售价、钱包、任务在 pilipala。
3. **任务与队列解耦。** 状态机在 Postgres；MQ 消息体只有 `job_id`。
4. **Worker 必须瘦。** 画布拓扑、剧本拆解、提示词拼装、Agent 编排、计费确认不进 worker；编排放业务 API（或独立编排服务，另开 ADR）。
5. **错误对人友好。** 用户看到稳定 `error_code` + 本地化短句；上游原文只进日志和 `provider_task`。
6. **Admin 不是第二产品。** 配置、排障、运营；不做另一套创作台。
7. **生成结果原样返回。** pilipala 不对模型输出做水印、元数据注入或转码，不引入 ffmpeg 等媒体系统依赖。

## 非目标（Non-goals）

- 不把 NewAPI / qfzy-api 做成业务后端，不在网关与 pilipala 之间做双用户、双额度、双账单。
- 不自建 GPU / ComfyUI 集群，不把画布做成通用工作流 IDE。
- 不做电商、广告、设计等全品类工具；与短剧无关的能力默认不做。
- M8 之前不做企业级多人实时协同、3D 导演台、公开模型市场。
- 不把管理后台做成第二个 C 端。
- 不重写 `docs/` 下的 Fumadocs 公开站点来承载工程文档。
- 托管模式不在浏览器保存供应商 Key；本地直连只作调试路径，不是商业路径。

社区 / 模板广场、对外 API 与 Agent Skill **不再是非目标**，排在 [MILESTONES.md](./MILESTONES.md) 的 M7–M8。

## 成功长什么样

一个付费创作者打开 pilipala，贴进一段剧本：画布上自动出现角色卡、分镜宫格和镜头节点；他锁定主角形象，改两格分镜，一键批量出镜头视频，配上配音和配乐，导出一集 1–3 分钟的竖屏短剧。每次生成都先冻结、成功才扣、失败自动退；违规内容在提交前被拦下。运营在 admin 里看到渠道成本、成功率和收入。
